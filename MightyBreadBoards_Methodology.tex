\section{Proposed Method}
This project is about a calibration method using stacked ensemble. Figure 3.1 shows the block diagram of the air monitoring system. The proposed system uses an RRH62000 sensor to read PM, temperature and Humidity, then its readings are sent to the ESP32. The ESP32 then executes the stack ensembled algorithm to calibrate the readings into a more accurate one. Upon undergoing the stack ensemble, the calibrated data is now sent to the thingspeak and users can now display and view such data through their device using thingspeak.  

To gather data necessary for the machine training, the proposed project uses the Air Monitoring System built and collocates it besides the DENR standard PM monitoring system to serve as the calibration reference. The proposed model can read PM every 3 minutes and display it to the web and store it in a csv.
