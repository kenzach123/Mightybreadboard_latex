\section{Proposed Methods}
This project is about a calibration method using stacked ensemble. Figure \ref{fig:simplified_system} shows the block diagram of the air monitoring system. The proposed system uses an RRH62000 sensor to read PM, temperature and Humidity, then its readings are sent to the ESP32. The ESP32 then executes the stack ensembled algorithm to calibrate the readings into a more accurate one. Upon undergoing the stack ensemble, the calibrated data is now sent to the thingspeak and users can now display and view such data through their device using thingspeak.

To gather data necessary for the machine training, the proposed project uses the Air Monitoring System built and collocates it besides the DENR standard PM monitoring system to serve as the calibration reference. The proposed model can read PM every 3 minutes and display it to the web and store it in a csv.

\subsection{Algorithm}
Figure \ref{fig:stack_operation} shows the architecture of the stack ensemble in operation. During real-time prediction, the sensor inputs are simultaneously fed into the basic learners (RFR and SVR). Each base model generates a prediction based on the raw environmental and particulate readings. These predictions are then passed as inputs to the meta learner (MLR). The MLR model applies its learned regression weights and intercept to create its own predictions which is considered as the calibrated final output.

\vspace{1em}
\noindent \textbf{Data Gathering}

To gather the dataset for the training, an air monitoring system is designed to gather and log data to the ThingSpeak. Figure \ref{fig:data_gathering_flow} shows the flowchart of the data gathering, it starts with setting the channel id and write API of the ThingSpeak channels. Then it reads the gyro sensor and tests if 0.02 seconds has passed since the last tilt calculation. If this condition is true, the MCU computes the tilt angles of the system using complementary filter. Then the MCU tests if the tilt is $> 50$ degrees. When the condition is true it sets the variable ``capsize'' to ``1'', then it tests another condition if 15 seconds has passed since the last tilt was sent to the ThingSpeak. If the condition is true, it sends the value of variable ``capsize'' to the ThingSpeak. After sending it tests a condition if three minutes have passed since the last PM sensor was read, if the condition is met it takes the sensor readings of RRH62000 and sends it to the ThingSpeak.

\vspace{1em}
\noindent \textbf{Training}

Figure \ref{fig:stack_training} shows the architecture of the proposed stacked ensemble training model. The training process adopts a two-level configuration. The primary dataset is used to train the Random Forest Regression (RFR) and Support Vector Regression (SVR) as the Basic learners. Once trained, these base models are tested with another dataset, the prediction of these base models are paired with the reference values and are then used to train the Meta learner. After the Multiple Linear Regression (MLR) is trained, another dataset is passed to validate the performance of the stack ensemble.
